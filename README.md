
# Monitoring

Infrastructure monitoring project built as part of the roadmap.sh DevOps projects.

## Project Goals

- Collect system and infrastructure metrics.
- Configure Prometheus for metrics scraping.
- Visualize metrics with Grafana dashboards.
- Configure alerting and monitoring rules.
- Document the deployment and verification process.

## Technology Stack

- Prometheus
- Grafana
- Node Exporter
- Docker Compose

Project initialization.
